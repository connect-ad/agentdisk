Handling rate limits

Every workspace has a per-second request ceiling on top of its monthly quota. This page covers what an agent sees when it hits either, and how to back off correctly.

Retrying immediately on a 429 extends the window. Always honour Retry-After.

Backing off

Exponential backoff with jitter, capped at 30 seconds. The SDK does this for you; if you call the API directly, mirror it.

PYTHON COPY 
for attempt in range(6):
    r = disk.write(path, data)
    if r.status != 429:
        break
    wait = min(30, (2 ** attempt) + random.random())
    time.sleep(r.headers.get("Retry-After", wait))
