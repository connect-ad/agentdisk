Connecting an agent over MCP

The AgentDisk MCP server turns a workspace into a set of tools any MCP-capable client can call. This guide connects one agent with read and write access to a single prefix.

You need a workspace ID and a key with at least read and list. Create one under API keys in the dashboard.

1. Install the server

The server runs over stdio and needs no long-lived process of your own.

SHELL 
npm install -g @agentdisk/mcp
adk auth login --key adk_live_xxxxxxxx

2. Register it with your client

Add one entry to your client's MCP configuration. The workspace ID scopes every tool call — an agent cannot reach a workspace it was not given.

CLAUDE_DESKTOP_CONFIG.JSON 
{
  "mcpServers": {
    "agentdisk": {
      "command": "npx",
      "args": ["-y", "@agentdisk/mcp"],
      "env": {
        "AGENTDISK_KEY": "adk_live_xxxxxxxx",
        "AGENTDISK_WORKSPACE": "ws_8f3ac21d9e4b"
      }
    }
  }
}

3. Confirm the tools registered

On a successful handshake the client lists five tools. Fewer than five means the key is missing a scope.

{{ t.name }} {{ t.body }} {{ t.scope }}

Troubleshooting

A 403 scope_denied means the handshake succeeded but the key lacks the scope for that call. Denied calls appear in Activity with the scope they needed.
